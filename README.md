# Pradeep Kumar Rout — Portfolio

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript. No build step, framework, or external assets are required.

Company, university, and certification logos are stored in `assets/` so they load reliably on GitHub Pages. The Impetus, BPUT, and Datadog images were supplied for this site. The [Cognizant](https://commons.wikimedia.org/wiki/File:Cognizant_logo_2022.svg) and [BNY Mellon](https://commons.wikimedia.org/wiki/File:BNY_Mellon.svg) marks are included only to identify past employers; their respective trademarks remain with their owners.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Add the files in this folder to the repository's root. For a user site, name the repository `your-github-username.github.io`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
5. Wait for the Pages deployment to finish. GitHub will show the published URL in the Pages settings.

All site links and assets use relative paths, so the page works both at a user-site root and in a project repository subpath.
